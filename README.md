# 勇者は壺を割らずにいられない 〜時計じかけの魔王城〜

壺やタンスを見ると、調べずにいられない勇者たち。
魔王になって罠を仕掛け、やって来る勇者を迎え撃つ、放置×リズムのゲームです。

スマホ縦画面。ブラウザでそのまま遊べます。エンディングまで約30分。

**遊ぶ：https://kome0824.github.io/yutsubo/**

## 遊び方

- 勇者は罠を見つけると「お・つ・ぼ・だ」と言いながら調べます。最後の音で手下が罠を押して発動（放っておいても進みます）。
- 吹き飛んだ勇者がほかの罠に当たると連鎖。壊れた罠は残骸になり、残骸もまた発動します。
- 下の「強化」で金貨を使って、罠を増やしたり強くしたりします。罠は指で引っぱって、好きなマスへ動かせます（罠どうしは入れ替え）。
- **金色の勇者**：罠にちなんだ口上を言います。ひと言の最後の音で、画面を押して自分で発動。全部会心なら金貨10倍。ときどきフェイントもまざります。
- **ボス・真の勇者の口上**：長い口上の、ひと言ごとの最後の音で押します。全部会心なら、部屋じゅうの罠が発動する大連鎖。
- 勇者を倒すと噂が広まり、強い勇者が来ます。真の勇者を退けるとエンディング。
- 「城の建て直し」で、魔王の冠をもらってやり直せます（冠はずっと残るボーナスに使えます）。
- 「大時計を速める」とテンポが上がり、勇者も手下も音楽も速くなります。
- 設定から、音量・画面のゆれ・図鑑・実績（30個）・データを全部消す。
